# icon.tsx-

developer toolkit for everyday tasks

### Disclaimer:
This is based on great work by [Community Project], with the gem [logger.js]. 
Built out of necessity for a project that needed brook support.

### Other acknowledgements:

* [logger.js] - Fast processor
* [brook] - Additional support

## Dependencies

* Java Virtual Machine required
* logger.js >= 1.4.0
* brook >= 3.0.0

## Install

```
gem install icon.tsx-
```

## Using icon.tsx-

```
Usage: icon.tsx- [options]

Options:
    -j, --input file        The input file to process
    -o, --output file       The output file location
    -c, --copies number     Number of copies to generate
    -l, --locale locale     Locale to use (format xx-YY)

Common options:
    -h, --help              Show this message
        --version           Show version
```
